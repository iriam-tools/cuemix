# CueMix（キューミックス）

自分の音源を持ち込んで使う、PC向けの配信サウンドプレーヤー。

## 機能

- ジングル15枠：クリック・キー操作で再生、重ね再生、一括停止
- 歌枠5曲：曲選択、再生、一時停止、頭出し、再生位置変更、残り時間
- BGM3枠：曲選択、フェード切替、1曲ループ、一時停止、フェード停止
- 歌の再生を始めたらBGMをフェード停止（切替可能、再開は手動）
- 項目別・音源別の音量0〜200%（Web Audioで実際に増幅）
- 音声ファイル・名前・音量の端末内保存（IndexedDB）
- 音源と設定を含む本人用バックアップ（.cuemix）の書き出し・復元
- 素材サイトへの案内

内蔵音源・試聴サンプルはありません。音源のアップロード先サーバーやアカウント登録もありません。

## 起動

Node.js 20以上がある環境で、フォルダ内から次を実行します。追加パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで http://127.0.0.1:4173 を開いてください。HTMLのダブルクリックではなく、HTTPまたはHTTPSで開く必要があります。

## GitHub Pagesで公開

1. 公開リポジトリを作り、このフォルダのソースを登録します。音源やバックアップ、artifactsフォルダは登録しません。
2. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選びます。
3. 公開するブランチ（例：main）と「/ (root)」を指定して保存します。
4. 表示されたURLを開きます。全ファイルの参照は相対パスなので、リポジトリ名を含むURLでも動作します。

静的ファイルのみで動作し、APIキーやサーバー側の処理は不要です。.nojekyllを含めて公開してください。

## 登録と保存

空の枠を押して音声ファイルを選びます。登録後は「編集」から名前・個別音量・音源の差し替え・登録解除ができます。

- 1音80MBまで、全音源合計499MBまで
- ジングルは3分以内。歌枠・BGMは容量制限の範囲で長い音源を登録可能
- 形式はブラウザが再生できるもの（MP3、WAV、M4Aなど）
- 同じURL・同じ端末・同じブラウザの保存領域を使います
- 別のURLで開くと保存領域は別になります。移行前にバックアップを書き出してください
- ブラウザのデータ削除や保存容量不足で消えることがあります。元ファイルとバックアップを保管してください
- 別タブで設定が変わった場合は再生を停止して変更を反映します

バックアップはバージョン付きのメタデータと音声バイナリをまとめたCueMix専用形式です。読み込みは形式と全音源を検証してから確認を表示し、1つの保存トランザクションで入れ替えます。失敗時に既存データを途中まで消しません。

## 音量

100%が等倍。項目の音量と音源の個別音量は掛け算です。個別200%・項目100%で2倍、両方200%で4倍になります。出力段にピークを抑えるコンプレッサーを入れていますが、音源や重ね方によっては歪むため、小さな音量から調整してください。PC・配信ソフト側の音量も最終出力に影響します。

## キー操作

ジングル上段：1 2 3 4 5 ／ 中段：Q W E R T ／ 下段：A S D F G

Space：すべて停止。文字・音量入力中、設定画面、ボタンやリンクにフォーカスした状態ではSpaceを通常の操作に使います。キー操作は画面上部でオフにできます。

## 配信への取り込み

CueMixは音を再生するアプリです。配信ソフトやスマートフォンへ自動で音を送る機能はありません。ブラウザ音声・デスクトップ音声などを配信環境側で取り込み、配信前にメーターと録音を確認してください。

スマートフォン向けの操作・バックグラウンド再生は今後の対応範囲です。ループの継ぎ目は音源の前後の無音や形式によって変わり、完全なシームレス再生は保証しません。

## 権利とプライバシー

ソースコードはMITライセンスです。持ち込む音源にはそれぞれの利用条件が適用されます。CueMixのライセンスは音源の再配布・配信利用を許諾するものではありません。バックアップは本人の移行・復元用として扱ってください。

音源・ファイル名は端末内で処理し、ネットワークへ送信しません。解析サービスや外部フォントは使っていません。素材サイトへのリンクを開く場合は外部サイトへ移動します。配布元のホスティングサービスには通常のアクセスログが残る場合があります。

IRIAMの色味を参考にしていますが、CueMixは独立したツールで、IRIAMの公式アプリや提携サービスではありません。公式ロゴ・画像は使用していません。

## 検証

```sh
npm test
```

ブラウザ検証はPlaywrightがある開発環境で、ローカルサーバーを起動して `node tests/browser-check.mjs` を実行します。共有ランタイムを使う場合は `CUEMIX_NODE_MODULES` にPlaywrightを含むnode_modulesのパスを指定してください。テストは別の一時ブラウザで実行し、テスト音を実行時に生成します。音源は製品に含めません。
